# Tic Tac Toe Game in C

## About the Project

This is a simple console-based Tic Tac Toe game developed using the C programming language.

The project was created to practice fundamental programming concepts such as arrays, loops, conditional statements, functions, and user input handling.

## Features

- Two-player gameplay (X and O)
- 3x3 game board
- Players take turns choosing positions from 1 to 9
- Automatic win detection
- Draw detection
- Invalid input handling
- Prevents players from selecting occupied cells
- Option to play again

## Technologies Used

- Programming Language: C
- Standard Library: stdio.h
- Development Environment: Any compatible C compiler

## How to Play

1. Run the program.
2. Player X starts first.
3. Enter a number from 1 to 9 to select a position.
4. Player O takes the next turn.
5. The first player to get three symbols in a row, column, or diagonal wins.
6. If all nine cells are filled without a winner, the game ends in a draw.
7. Enter Y to play again or N to exit.

## Example Game Board

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

## How to Run

1. Download the `main.c` file.
2. Open it in a C development environment.
3. Compile the program using a C compiler.
4. Run the executable file.

For example, using GCC:

```bash
gcc main.c -o tictactoe
./tictactoe
```

On Windows, run `tictactoe.exe` after compiling.
